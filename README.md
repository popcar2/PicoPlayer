<h1 align="center"><a href="https://picoplayer.net">PicoPlayer</a></h1>
<h3 align="center">A tiny website for curated PICO 8 games</h3>

PicoPlayer is a non-commercial, open source, minimalist website that collects a curated list of PICO-8 games and makes them super convenient to play and sift through. No ads, no shovelware, no gotchas.

It's designed to be as fast and tiny as possible, jumping through tons of hoops to minify the file size and make it a superb experience for browsing and playing quality games. The end result is a website that can be installed as a PWA and used offline where you can play 150+ games by downloading less than 4 megabytes total!

If you'd like to read more on how it works, see the [technical details page](https://picoplayer.net/technical_deets).

# Contributing

The project is pretty much finished, but I'm open to adding more games, fixing bugs, or optimizing the project further.

There is no hard requirement for adding games, I'll add it if I like it! Feel free to open an issue to request a certain game.

However, here are some *general* guidelines:

* It should be a game, not an animation or music-only experience.
* It shouldn't be a tech demo or technically impressive game that turns out to be rough to play
* The game should be easy to pick up and play without reading paragraphs of text in the description.
* The game should preferably work well with mobile controls and controllers.
* I have a bias for games that are unique and varied. There are only so many classic 2D platformers and metroidvanias that can be on the website.
* It needs to be legal to redistribute - only request games that are CC, open source, or ones you own.
