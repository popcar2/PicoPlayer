About

TinyFun is a minimalist site that collects some of my favorite PICO-8 games and makes them super convenient to play and sift through.

The website is partially inspired by UFO 50, a collection of great retro-style games that follows the same concept: letting you explore a big collection of quality games without getting in your way.

The PICO-8 player is separated from each game and cached, so it usually only downloads ~50KB per game. The games also get hotswapped into the same frame, so you don't have to reload the page like other webgame sites. The website itself uses Fixi, which is kinda like a tiny version of HTMX. This keeps the website super simple and fast.

All games included on this site are Creative Commons (usually CC4-BY-NC-SA) or have been added with explicit permission by the creator.

TinyFun was made by popcar2 (admittedly, with help from Claude).
